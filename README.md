# Python Banking Application

A beginner-level banking management system built in Python.

## Features

- User registration
- Secure password hashing
- Login authentication
- Checking and savings accounts
- Deposits
- Withdrawals
- Transfers
- Transaction history

## Technologies

- Python
- File-based storage
- SHA-256 password hashing

## Future Improvements

- SQLite database
- GUI interface
- Object-oriented redesign
